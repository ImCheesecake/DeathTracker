# Libraries

Death Tracker embeds these libraries unchanged, for its minimap button. Each belongs to its
authors.

| Library | Version | License | Source |
|---|---|---|---|
| LibStub | 1.0 | Public domain | https://www.wowace.com/projects/libstub |
| CallbackHandler-1.0 | minor 8 | Ace3 BSD-style (part of Ace3) | https://www.wowace.com/projects/callbackhandler |
| LibDataBroker-1.1 | minor 4 | None stated by the author | https://github.com/tekkub/libdatabroker-1-1 |
| LibDBIcon-1.0 | minor 57 | Ace3 BSD-style | https://www.curseforge.com/wow/addons/libdbicon-1-0 |

LibDBIcon's CurseForge page says "Ace3 Style BSD"; the `.toc` in its own download says "All Rights
Reserved". Death Tracker goes by the project page, as Altisan does.

LibDataBroker-1.1's repository has no license file. It is embedded the way nearly every addon with
a minimap button embeds it.
